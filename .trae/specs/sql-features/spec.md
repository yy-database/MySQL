# YYKV SQL 特性推进 - 产品需求文档

## 概述
- **摘要**: 推进 YYKV 项目的 SQL 相关特性，利用现有的 oak-sql 解析器和 yyds-gateway 中的 SQL 处理能力，增强 SQL 解析、执行和优化能力。
- **目的**: 提升 YYKV 对 SQL 查询的支持，使其能够处理更复杂的 SQL 语句，为用户提供更强大的查询能力。
- **目标用户**: 开发人员、数据分析师、需要使用 SQL 进行数据查询的终端用户。

## 目标
- 增强 SQL 解析能力，支持更多 SQL 语法结构
- 完善 SQL 执行引擎，提高查询性能和可靠性
- 优化 SQL 到操作图的转换逻辑
- 增加 SQL 相关的测试覆盖
- 提供更好的 SQL 错误处理和用户反馈

## 非目标（范围外）
- 不重新实现 SQL 解析器，而是基于现有的 oak-sql 解析器进行扩展
- 不支持所有 SQL 标准特性，而是专注于核心查询功能
- 不修改底层存储引擎的实现

## 背景与上下文
- 项目目前使用 oak-sql 作为 SQL 解析器，版本为 0.0.7
- yyds-gateway 中已有基础的 SQL 处理逻辑，但功能有限
- 支持基本的 SELECT、INSERT、UPDATE、DELETE、CREATE、DROP 语句
- 已实现简单的表达式处理和操作图生成

## 功能需求
- **FR-1**: 增强 SELECT 语句支持，包括 JOIN、GROUP BY、ORDER BY、LIMIT 等子句
- **FR-2**: 完善 INSERT 语句支持，支持批量插入和指定列插入
- **FR-3**: 增强 UPDATE 和 DELETE 语句的条件处理能力
- **FR-4**: 完善 CREATE TABLE 语句，支持列定义和约束
- **FR-5**: 增加 SQL 函数支持，包括聚合函数和标量函数
- **FR-6**: 实现 SQL 到操作图的优化转换
- **FR-7**: 提供更详细的 SQL 错误信息和语法提示

## 非功能需求
- **NFR-1**: SQL 解析和执行性能应满足生产环境要求
- **NFR-2**: 错误处理应友好，提供清晰的错误信息
- **NFR-3**: 代码应遵循项目的编码规范和文档要求
- **NFR-4**: 新增功能应具有良好的测试覆盖

## 约束
- **技术**: 基于现有的 oak-sql 解析器，不得引入新的解析器依赖
- **业务**: 保持与现有系统的兼容性
- **依赖**: 依赖 yykv-operators 库进行操作图生成

## 假设
- oak-sql 解析器能够解析所需的 SQL 语法
- 现有的操作图执行引擎能够处理增强后的查询需求
- 项目的编译和测试环境正常

## 验收标准

### AC-1: 增强 SELECT 语句支持
- **给定**: 复杂的 SELECT 语句，包含 JOIN、GROUP BY、ORDER BY、LIMIT 等子句
- **当**: 执行该语句时
- **然后**: 语句应被正确解析并执行，返回预期结果
- **验证**: `programmatic`

### AC-2: 完善 INSERT 语句支持
- **给定**: 包含多个值的 INSERT 语句
- **当**: 执行该语句时
- **然后**: 所有值应被正确插入到指定表中
- **验证**: `programmatic`

### AC-3: 增强 UPDATE 和 DELETE 语句
- **给定**: 包含复杂条件的 UPDATE 或 DELETE 语句
- **当**: 执行该语句时
- **然后**: 应只更新或删除符合条件的记录
- **验证**: `programmatic`

### AC-4: 完善 CREATE TABLE 语句
- **给定**: 包含列定义和约束的 CREATE TABLE 语句
- **当**: 执行该语句时
- **然后**: 应创建具有指定结构的表
- **验证**: `programmatic`

### AC-5: 增加 SQL 函数支持
- **给定**: 包含聚合函数或标量函数的 SQL 语句
- **当**: 执行该语句时
- **然后**: 函数应被正确执行并返回预期结果
- **验证**: `programmatic`

### AC-6: SQL 到操作图的优化转换
- **给定**: 复杂的 SQL 查询
- **当**: 解析该查询时
- **然后**: 应生成优化的操作图，提高执行效率
- **验证**: `programmatic`

### AC-7: 详细的 SQL 错误信息
- **给定**: 语法错误的 SQL 语句
- **当**: 解析该语句时
- **然后**: 应返回清晰的错误信息，指出错误位置和原因
- **验证**: `human-judgment`
