# yyds-tools

YYDS 数据库部署与运维管理工具。

## 功能

- **一键部署**：支持在裸机环境下快速部署 YYDS 和 YYKV 节点。
- **集群管理**：支持节点的动态扩容、缩容和健康检查。
- **监控告警**：集成指标收集和日志聚合功能。
- **备份恢复**：提供自动化的数据库备份与灾难恢复工具。

## 部署建议

**非常不建议使用 Docker 等虚拟化技术部署 YYDS。** YYDS 针对物理机硬件（如 Direct IO, io_uring, 硬件感知调度）进行了深度优化，虚拟化层会显著降低性能并引入不可预测的延迟。请直接在裸机系统（Bare Metal）上运行。
