# 调度系统

YYDS 生态中包含两个层面的调度器，分别负责底层的 I/O 优先级管理和上层的后台任务编排。

## 1. I/O 调度器 (yykv-scheduler)

`yykv-scheduler` 是 YYKV 存储引擎的 I/O 调度中心。它通过对 I/O 请求进行优先级分类、实现多分片（Sharding）并发控制以及确保公平调度，保证了前台查询请求在复杂后台维护任务（如 Compaction/GC）干扰下仍能保持低延迟。

### 核心特性

- **优先级驱动调度**: 将 I/O 请求分为三个级别：
  - **High**: 关键元数据读写、WAL 顺序写入。这些请求会抢占执行资源，确保数据库的响应性。
  - **Medium**: 标准用户 SQL 查询、KV 读写请求。
  - **Low**: 后台 Compaction、数据分层 (Tiering)、垃圾回收 (GC)。仅在系统负载低时执行。
- **I/O 分片架构 (Sharding)**: 基于 `PageId` 或 `Offset` 实现多线程分片，消除单队列锁竞争。
- **并发控制与背压**: 自动感知队列积压，向上传递等待信号，防止 NVMe 驱动器队列溢出和内存 OOM。

## 2. 任务调度器 (yyds-task)

`yyds-task` 是 YYDS 生态的后台任务调度与管理系统，负责处理非即时完成的异步操作和定时任务。

### 核心特性

- **异步任务编排**: 处理大规模数据迁移、索引重建等耗时操作。
- **分布式 Cron 调度**: 负责周期性计费汇总、过期数据清理及系统健康检查。
- **WAL 持久化 (WAE)**: 任务提交后先写入预写日志 (WAL)，确保在节点故障时任务不丢失并可在集群内重新调度。
- **状态追踪**: 提供任务全生命周期管理，支持重试、挂起与进度监控。
