# Vector 向量协议详解

**we-trust-vector** 是 YYKV 针对 AI 时代设计的专用协议扩展，专门用于处理高维向量的存储与检索 (Vector Search)。

## 1. 协议特性

不同于传统的 KV 协议，Vector 协议在报文层面支持：
- **维度定义**: 在写入时指定向量维度（如 768, 1536）。
- **距离度量 (Distance Metrics)**: 支持在查询报文中指定 `L2` (欧氏距离)、`Cosine` (余弦相似度) 或 `IP` (内积)。
- **Top-K 查询**: 专用指令集用于快速返回最相似的 K 个结果。

## 2. 数据编码

向量数据在传输时采用紧凑的二进制浮点数组格式：
- **`f32` 数组**: 标准精度。
- **`f16` / `Int8` 量化**: 支持在协议层进行数据量化压缩，节省 50% - 75% 的网络带宽。

## 3. 搜索算子映射

Vector 指令直接映射到 YYKV 的底层向量索引（如 HNSW 或 IVF-Flat）：
- `MessageType::Query` 携带向量负载。
- 存储节点利用 `yykv-compute` 的向量加速模块进行并行检索。

## 4. 应用场景

- **RAG (检索增强生成)**: 为大语言模型提供实时、高效的知识库检索。
- **图像/视频搜索**: 存储特征向量并实现快速以图搜图。
- **推荐系统**: 基于用户行为向量实现实时个性化推荐。
