# Reference

This section contains technical references for the YYKV (YongYuan Key-Value) storage kernel.

## Storage Components

- `yykv-hal`: Hardware Abstraction Layer.
- `yykv-io`: Async I/O engine.
- `yykv-allocator`: Raw disk space allocator.
- `yykv-layout`: Physical data layout.
- `yykv-compaction`: LSM-like compaction engine.
