# SQL Server Protocol

**we-trust-sqlserver** provides basic support for the TDS (Tabular Data Stream) protocol.

## Features

- **TDS Adaptation**: Implements core parts of the TDS protocol used by SQL Server.
- **Enterprise Integration**: Simplifies integration with the .NET ecosystem and SQL Server drivers.

## Use Cases

- Access YYKV from .NET/C# applications using the SqlClient driver.
