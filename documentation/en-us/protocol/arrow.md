# Apache Arrow Protocol

**we-trust-arrow** provides vectorized data exchange capabilities for YYKV, a key component for high-performance OLAP (Online Analytical Processing).

## 1. Why Use Arrow?

Traditional row-based data transmission wastes significant CPU time on data serialization and type conversion when handling massive analytical queries. With the Arrow protocol, YYKV can:
- **Zero-Copy Exchange**: Columnar data blocks generated by the storage engine are sent directly in Arrow IPC format, requiring no parsing by the client before computation.
- **Memory Alignment**: Packet structures fully comply with SIMD instruction set requirements, accelerating filtering and aggregation operations.

## 2. Protocol Integration

The Arrow protocol exists as an extension type within We-Trust:
- When `MsgType` is `MessageType::Query` and an Arrow output format is specified, the payload contains standard **Arrow Schema** and **RecordBatches**.
- Supports **Dictionary Encoding**, drastically compressing data transmission for low-cardinality columns.

## 3. Application Scenarios

- **AI/ML Integration**: Seamlessly interfaces with Python's `pandas` and `pyarrow` to feed high-speed feature data into machine learning models.
- **Big Data Processing**: Acts as a data source for Spark or Flink, achieving sub-second columnar data reads.
- **BI Reporting**: Accelerates the aggregation and display of extremely large datasets.
