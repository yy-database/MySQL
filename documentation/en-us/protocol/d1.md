# Cloudflare D1 & SQL Server Protocols

This page covers compatibility protocols targeting edge Web environments and enterprise legacy environments.

## 1. Cloudflare D1 Compatibility (we-trust-d1)

**we-trust-d1** aims to allow developers to use the Cloudflare D1 HTTP query interface to interact directly with YYKV storage clusters.

### 1.1 Protocol Features
- **HTTP/JSON Transport**: Uses lightweight JSON format to transmit SQL statements and result sets.
- **Stateless Connections**: Ideal for Serverless environments, as no long-lived connections are required.
- **D1 SDK Compatibility**: Developers can use D1 interface definitions from `@cloudflare/workers-types` to call YYKV.

### 1.2 Usage Scenarios
- **Serverless Functions**: Low-latency access to YYKV storage from Cloudflare Workers or Vercel Functions.

## 2. SQL Server Compatibility (we-trust-sqlserver)

**we-trust-sqlserver** implements basic portions of the TDS (Tabular Data Stream) protocol, providing support for traditional .NET applications and enterprise BI tools.

### 2.1 Protocol Mapping
- **TDS Packet Parsing**: Identifies `Batch Request` and `RPC Request` packets sent by SQL Server clients.
- **Type Mapping**: Maps SQL Server types such as `money`, `datetime2`, and `uniqueidentifier` to `YYValue`.

### 2.2 Usage Recommendations
- **Legacy System Migration**: Switch backends to high-concurrency YYKV by simply changing connection strings, without rewriting large amounts of C# code.
