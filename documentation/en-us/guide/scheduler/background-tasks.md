# Background Maintenance and Automation (Maintenance)

YYDS achieves self-healing and self-optimization of the storage system through a series of background scheduling tasks.

## Core Maintenance Tasks

### 1. LSM-Tree Compaction
Scheduled by the `yykv-compaction` module:
- **Trigger Mechanism**: Monitors the number of files and space amplification rate in each level.
- **Scheduling Policy**: Uses `Low Priority` I/O to ensure no impact on online business.
- **Garbage Collection**: Cleans up invalid Tombstone records to release physical space.

### 2. Cold/Hot Data Tiering
Managed by the `yykv-tiering` module:
- **Hotspot Awareness**: Real-time statistics on the access frequency of `PageId`.
- **Automatic Migration**: Scheduling tasks promote hot data to NVMe and demote cold data to HDD.
- **Policy Control**: `yykv-policy` defines tiering rules for different tenants.

### 3. Near-Real-Time Index Synchronization (NRT Indexing)
Completed by `yykv-index` in combination with `yykv-event`:
- **Streaming Writes**: Captures WAL event streams and asynchronously updates inverted and vector indexes.
- **Segment Merging**: Periodically schedules merge tasks for index segments to optimize query performance.

## Resource Control and Quotas

- **yyds-quota**: Limits the total bandwidth usage of background tasks to prevent them from "overpowering" primary tasks.
- **yyds-billing**: Audits and bills for I/O and storage space generated by background tasks.
