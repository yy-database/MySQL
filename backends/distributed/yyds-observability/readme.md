# Distributed Observability Engine

`yyds-observability` is the distributed observability engine for the YYDS ecosystem.

## Features

- **Tracing**: Distributed request tracing across components based on OpenTelemetry.
- **Metrics**: Collects performance metrics from core components such as storage, compute, and consensus, supporting export to Prometheus.
- **Structured Logging**: Provides a unified structured logging and context propagation mechanism.
