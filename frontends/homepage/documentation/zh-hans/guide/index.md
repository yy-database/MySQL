# 指南

欢迎来到 YYDS (獨一分布式存储) 官方文档。

YYDS 是独一数据库生态的底层存储基石，专注于在裸硬件上实现极致性能与多租户隔离。

如果你已经有一个正在运行的 YYDS 实例，或者正在使用我们的云服务，请点击这里了解如何连接并开始存取数据。

### 🛠️ [部署指南：安装与运行](./deploy)
如果你需要从零开始搭建自己的 YYDS 集群，或者在本地开发环境中运行，请点击这里了解系统要求与安装步骤。
