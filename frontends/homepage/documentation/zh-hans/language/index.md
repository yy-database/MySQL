# RBQ 语言

## 概述

RBQ (Resource Binding Query) 是一种现代化的查询语言，专为 YYKV 存储引擎设计，提供简洁、强大的数据查询和处理能力。RBQ 语言结合了 SQL 的表达能力和现代编程语言的灵活性，旨在为开发者提供一种直观、高效的数据操作方式。

## 核心特性

- **简洁的语法**：RBQ 语言采用简洁、直观的语法，易于学习和使用。
- **强大的表达能力**：支持复杂的查询操作，包括过滤、排序、聚合等。
- **类型安全**：内置类型系统，提供编译时类型检查。
- **与 YYKV 深度集成**：优化的执行计划，充分利用 YYKV 的存储特性。
- **支持复杂数据结构**：原生支持嵌套结构、数组等复杂数据类型。

## 快速开始

### 基本查询

```rbq
// 查询所有用户
from users

// 查询特定用户
from users where id = 1

// 带排序的查询
from users order by created_at desc

// 带限制的查询
from users limit 10
```

### 复杂查询

```rbq
// 带过滤和排序的查询
from users 
where age > 18 
order by created_at desc 
limit 10

// 带聚合的查询
from users 
group by age 
select age, count(*) as user_count
```

## 语法参考

### 基本语法结构

```rbq
from <table_name>
[where <condition>]
[group by <column>]
[select <columns>]
[order by <column> [asc|desc]]
[limit <number>]
```

### 数据类型

- **整数**：`123`, `-456`
- **浮点数**：`123.456`, `-78.90`
- **字符串**：`"hello"`, `'world'`
- **布尔值**：`true`, `false`
- **数组**：`[1, 2, 3]`, `["a", "b", "c"]`
- **对象**：`{ "name": "John", "age": 30 }`

### 操作符

- **算术操作符**：`+`, `-`, `*`, `/`, `%`
- **比较操作符**：`=`, `!=`, `<`, `<=`, `>`, `>=`
- **逻辑操作符**：`and`, `or`, `not`
- **集合操作符**：`in`, `not in`

## 与 YYKV 集成

RBQ 语言与 YYKV 存储引擎深度集成，提供以下优势：

- **优化的执行计划**：RBQ 解析器会生成针对 YYKV 存储特性优化的执行计划。
- **高效的数据访问**：直接操作 YYKV 的存储结构，减少数据转换开销。
- **支持事务**：与 YYKV 的事务机制无缝集成。
- **实时查询**：支持实时数据查询和处理。

## 示例

### 1. 基本查询

```rbq
// 查询所有用户
from users
```

### 2. 带条件的查询

```rbq
// 查询年龄大于 18 的用户
from users where age > 18
```

### 3. 带排序和限制的查询

```rbq
// 查询最近创建的 10 个用户
from users order by created_at desc limit 10
```

### 4. 聚合查询

```rbq
// 按年龄分组，统计每个年龄的用户数量
from users group by age select age, count(*) as user_count
```

### 5. 复杂条件查询

```rbq
// 查询年龄大于 18 且姓名包含 "John" 的用户
from users where age > 18 and name like "%John%"
```

## 最佳实践

1. **使用索引**：为常用查询字段创建索引，提高查询性能。
2. **优化条件**：将最严格的条件放在前面，减少数据扫描范围。
3. **合理使用聚合**：聚合操作可能会增加计算开销，合理使用。
4. **避免复杂嵌套**：过于复杂的嵌套查询可能会影响性能。
5. **使用参数化查询**：避免 SQL 注入风险。

## 故障排除

### 常见错误

1. **语法错误**：检查 RBQ 语句的语法是否正确。
2. **类型错误**：确保操作符两边的类型匹配。
3. **权限错误**：确保用户有足够的权限执行查询。
4. **性能问题**：检查查询是否过于复杂，是否需要优化。

### 调试技巧

1. **使用 EXPLAIN**：查看查询的执行计划，了解查询的执行过程。
2. **简化查询**：逐步构建查询，定位问题所在。
3. **检查数据**：确保数据符合预期，没有异常值。
4. **监控性能**：使用 YYKV 的监控工具，查看查询的执行性能。

## 总结

RBQ 语言是一种强大、灵活的查询语言，为 YYKV 存储引擎提供了直观、高效的数据操作能力。通过本文档的学习，您应该能够掌握 RBQ 语言的基本使用方法，并在实际项目中应用它来处理复杂的数据查询和处理需求。
