# Cloudflare D1 & SQL Server 协议详解

本页面涵盖了针对边缘 Web 环境和企业级传统环境的兼容性协议。

## 1. Cloudflare D1 兼容 (we-trust-d1)

**we-trust-d1** 旨在让开发者能够使用 Cloudflare D1 的 HTTP 查询接口直接操作 YYKV 存储集群。

### 1.1 协议特点
- **HTTP/JSON 承载**: 采用轻量级的 JSON 格式传输 SQL 语句和结果集。
- **无状态连接**: 适合 Serverless 环境，无需维持长连接。
- **D1 SDK 兼容**: 开发者可以使用 `@cloudflare/workers-types` 中的 D1 接口定义来调用 YYKV。

### 1.2 应用场景
- **Serverless 函数**: 在 Cloudflare Workers 或 Vercel Functions 中低延迟访问 YYKV 存储。

---

## 2. SQL Server 兼容 (we-trust-sqlserver)

**we-trust-sqlserver** 实现了 TDS (Tabular Data Stream) 协议的基础部分，为传统的 .NET 应用和企业级 BI 工具提供支持。

### 2.1 协议映射
- **TDS 报文解析**: 识别 SQL Server 客户端发送的 `Batch Request` 和 `RPC Request`。
- **类型映射**: 将 SQL Server 的 `money`, `datetime2`, `uniqueidentifier` 等类型映射为 `YYValue`。

### 2.2 使用建议
- **遗留系统迁移**: 无需重写大量 C# 代码，只需更换连接字符串即可将后端数据库切换为高并发的 YYKV。
