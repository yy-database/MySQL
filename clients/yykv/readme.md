# yykv

YYKV 高性能键值存储客户端库。

> **注意**：本仓库是 **客户端库**，用于在你的 Rust 应用中集成 YYKV 存储能力。如果你需要部署运行 YYKV/YYDS 服务端，请使用 [yyds-tools](../../servers/yyds-tools)。

## 功能

- **分布式连接管理**：管理与存储节点的连接与重连。
- **租户隔离**：内置租户 ID 路由，确保数据安全隔离。
- **协议封装**：基于 We-Trust 原生高性能通信协议进行请求/响应。
- **基础 KV 操作**：提供 `get / put / delete / query` 等异步接口，便于应用集成。
