# Apache Arrow Protocol

**we-trust-arrow** provides vectorized data exchange capabilities for YYKV and is a key component for high-performance OLAP (Online Analytical Processing).

## 1. Why Arrow?

Traditional row-based data transmission wastes significant CPU time on serialization and type conversion when handling massive analytical queries. Through the Arrow protocol, YYKV can achieve:
- **Zero-Copy Exchange**: Columnar data blocks generated by the storage engine are sent directly in Arrow IPC format, allowing clients to perform computations without parsing.
- **Memory Alignment**: The message structure fully complies with SIMD instruction set requirements, accelerating filtering and aggregation operations.

## 2. Protocol Integration

The Arrow protocol exists as an extended type within We-Trust:
- When `MsgType` is `MessageType::Query` and an Arrow output format is specified, the Payload contains standard **Arrow Schema** and **RecordBatches**.
- Supports **Dictionary Encoding**, which significantly compresses data transmission for low-cardinality columns.

## 3. Use Cases

- **AI/ML Integration**: Seamlessly interfaces with Python's `pandas` and `pyarrow`, feeding high-speed feature data from YYKV into machine learning models.
- **Big Data Processing**: Acts as a data source for Spark or Flink, enabling sub-second columnar data reading.
- **BI Reporting**: Accelerates the aggregation and display of ultra-large scale datasets.
